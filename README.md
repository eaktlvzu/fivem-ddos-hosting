## FiveM 服务器到底需要什么

先说最容易被忽略的事实：你的玩家上限和主机商关系不大。FiveM 官方默认用 OneSync Infinity 支持最多 48 名玩家，想超过 48 人就得向 Cfx.re 购买 Element Club 订阅——Argentum 档 $15/月（64 slots）、Aurum 档 $25/月（Infinity 下 128 slots）、Platinum 档 $50/月（Infinity 下 2048 slots），价格另加 VAT。这笔钱无论你在哪家买服务器都省不掉，很多讲 fivem hosting 的文章根本不提，导致玩家买了服务器才发现开不了 60 人。

服务器本身的要求倒不复杂。官方推荐 x86-64 系统跑 Linux 或 Windows，有像样的上行带宽和多核处理器。实际部署靠 txAdmin 完成大半：它提供实时控制台、玩家管理和定时重启，ESX、QBCore、QBox 框架都能通过它的配方装上，前两者还需要一个 MySQL 数据库，纯 vMenu 自由模式则不需要。

性能方面要泼一盆冷水。FiveM 的主循环跑在单个线程上，服务器卡不卡主要取决于脚本质量和资源数量，任何主机商都没法承诺“零卡顿”——LBC Hosting 就在自己的 FAQ 里写明，他们能保证的只有套餐标注的 CPU 预算。所以挑配置时，单核性能比核心数量更值得看。
